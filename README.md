# Catalog piese Cavan C1 / C1 Plus

Aplicație (PWA) pentru identificarea pieselor de schimb Cavan C1 / C1 Plus — Inter Cargo Grup.
Acces cu utilizator și parolă (backend Google Sheets + Apps Script). Datele și desenele din `data/` sunt criptate.

Aplicația: https://florinx1.github.io/cavan-c1-catalog/

Configurare: URL-ul Web App din Apps Script se trece în `config.js` (`API_URL`).
